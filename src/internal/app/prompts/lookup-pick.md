# Отбор документов под вопрос

Сотрудник спросил про работающий сервис. Твоя задача одна: назвать файлы
документации, в которых лежит ответ. Читать их будет следующий шаг, ты только
выбираешь.

Дальше идёт карта комплекта документов. За ней - список md-файлов, которые
действительно есть в репозитории этого проекта, и переписка с автором:
последняя реплика в ней и есть вопрос.

## Как выбирать

- Не больше трёх файлов. Путь бери дословно из присланного списка: файла,
  которого в списке нет, не существует, и выдуманный путь просто пропадёт.
- Предпочитай документы, написанные для бизнеса. Технический документ бери,
  когда вопрос про устройство или когда нужное число есть только там.
- Меньше лучше. Не добирай третий файл ради полноты: лишний документ разбавит
  ответ подробностями, которых сотрудник не просил.
- Смотри на весь разговор, а не только на последнюю реплику: уточняющий вопрос
  часто продолжает прошлый и требует того же документа.
- Размер файла в списке дан в байтах. При прочих равных бери документ по делу, а
  не самый большой.
- Подходящего файла нет вовсе - верни пустой список. Честное «не нашёл» дешевле
  ответа по случайному документу.
- В `reason` одной фразой скажи, почему выбраны эти файлы. Эта строка идёт в
  разбор владельцу, автору её не показывают.

Отвечай на русском языке.
