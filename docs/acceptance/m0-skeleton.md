# Приёмка: M0, каркас сервиса

Дата: 2026-08-08, релиз 0.1.0. Срез: бот поднимается, узнаёт автора по белому
списку, показывает список проектов из базы и подтверждает выбор; приёма
обращений в нём ещё нет.

## Что проверено

Локально: `make ci-check` зелёный, `docker compose up` доводит postgres, миграции
и приложение до healthy, healthcheck отвечает 0 при живой базе и 1 при мёртвой,
`kill -TERM` даёт `shutdown` в логе.

Живьём: `/start` от автора из белого списка вернул список проектов кнопками,
счётчик `users` вырос с нуля до одного, нажатие на проект дало
`project_selected`. В логе нет ни имени, ни username, ни текста сообщения -
человек в логах это `user_id`. Выкат прошёл целиком: `app_revision` в рантайме
совпал с HEAD.

Две проверки отказа (посторонний ID, сообщение в групповом чате) закрыты
решением владельца без прогона: обе ветки - три строки в одном middleware, через
который идут все апдейты, а путь «разрешено» на нём проверен живьём. Риск принят
осознанно - чужой `user_id` в логе будет виден.
