# Паспорт приёмки: M0, каркас сервиса

Спека - [plan-m0-skeleton.md](../plans/plan-m0-skeleton.md). Приёмка проходит в
dev-контуре; пункты, которые не требуют контура, проверяются локально.

## Что должно работать

Бот поднимается, узнаёт автора по белому списку, показывает список проектов из
базы и подтверждает выбор. Приёма обращений в срезе нет: это следующий срез.

## Проверки

| Что делаю | Что должен увидеть | Статус |
| --- | --- | --- |
| `make ci-check` локально | миграции применены, тесты, vet и build зелёные | пройдено 2026-08-08 |
| `docker compose up` в `src` | postgres healthy, `migrate` вышел с кодом 0, `app` healthy | пройдено 2026-08-08 |
| `/app healthcheck` при живой и мёртвой базе | код возврата 0 и 1 соответственно | пройдено 2026-08-08 |
| запуск бинаря с боевым токеном | в логе `starting`, `db_connected`, `bot_started` | пройдено 2026-08-08 |
| `kill -TERM` | в логе `shutdown`, процесс завершился | пройдено 2026-08-08 |
| `/start` от автора из белого списка | список проектов кнопками, в базе строка `users` | пройдено 2026-08-08 |
| нажатие на проект | «Проект X выбран», в логе `project_selected` | пройдено 2026-08-08 |
| чтение лога целиком | ни имени, ни username, ни текста сообщения | пройдено 2026-08-08 |
| push в `dev` | образ `sha-<commit>` в GHCR, выкат Coolify, `app` healthy, версия в логе равна коммиту | пройдено 2026-08-08 |
| `/start` от постороннего ID | отказ, в базе ни строки, в логе `access_denied` | не проверялось |
| сообщение боту в групповом чате | «Бот работает только в личной переписке» | не проверялось |

Живой диалог, выкат `sha-32bae11f`: `start` и `project_selected` с `user_id`
автора, счётчик `users` вырос с нуля до одного, в логе ни имени, ни username,
ни текста. Автодеплой проверен целиком: `app_revision` в рантайме равен HEAD
ветки `dev`.

Две проверки отказа закрыты решением владельца без прогона. Обе ветки - это
три строки в одном middleware, через который проходят все апдейты, и путь
«разрешено» на нём проверен живьём. Риск принят осознанно: если посторонний
всё же пройдёт, это видно по появлению чужого `user_id` в логе.

## Известные ограничения среза

- Любое сообщение, кроме `/start` и нажатия на проект, бот молча игнорирует:
  обработчиков в M0 нет.
- Healthcheck пингует только базу и не видит мёртвый поллер.
- Один неудачный `getMe` на старте роняет процесс, поднимает только
  политика рестарта. Егресс к Telegram с VPS моргает даже с пином DC.
- `GITHUB_TOKEN` заведён в переменных контура заранее, но в Compose не
  проброшен и в контейнер не попадает: код M0 его не читает. Подключается в M2.
- Один токен обслуживает один long-poller: локальный запуск и dev-контур
  одновременно дают 409 Conflict.
