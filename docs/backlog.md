- [ ] **M2** Интервью и публикация: контракт готовности, добивание раундами по
      2-3 вопроса, саммари с подтверждением, создание issue через outbox с
      авторством в шапке и метке, ответ автору. Замыкает Core.
- [x] **M3** Dev-контур: Coolify, база, автодеплой из `dev`, живой прогон.
      Сделан вместе с M0: без контура срез нечем принимать.
- [ ] **M4** Просмотр и жизненный цикл: список тикетов, карточка, статусы через

- [ ] **M5** Защита от мусора: дубли, лимиты. Нужен при открытии доступа шире
      белого списка.
- [ ] **M6** Брифинг: режим «завести новый проект», интервью по промту
      брифовщика, на выходе PRD документом в чат. Спека пишется после первого
      живого прогона промта с заказчиком вне бота. Три решения принимаются на

      автор адресует сообщение одному из двух активных разговоров, и правка
      тикет-центричных текстов бота под пришедшего заказчика.
- [ ] **M7** Вопросы по проекту: ответ из накопленной документации. Условие
      входа - PRD проектов и история тикетов в системе.

M0-M3 составляют Core и дают работающий сервис. Первая версия - только создание
тикета; M4 делает из сервиса трекер и в неё не входит. Срок плавающий по
решению владельца 2026-08-08: оценка показала объём двух полных срезов, а за
датой нет внешнего события.

Порядок после M2: сначала M4, потом M6. M4 замыкает контур первой функции - без
статусов автор возвращается спрашивать в личку, и тикеты работают наполовину.
M6 добавляет новую функцию, и его срочность снята тем, что промт брифовщика
работает в чате Claude уже сейчас, без бота.
