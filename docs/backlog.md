## Активные задачи

- [ ] **Выбрать модель диалога по живым прогонам**: текущая взята наугад.
      Сравнивать по `ms` и `tokens_think` в логе, кандидат переключается
      переменной контура без релиза.
- [ ] **Очередь не отличает невосстановимый отказ от временного**: отказ по
      правам проходит все шесть попыток, и честный ответ доходит до автора через
      минуту-две. `isDenied` известен уже на первой. Каркасное: признак
      «повторять нет смысла» должен возвращать сам ход работы.
- [ ] **Расширять `GITHUB_TOKEN` при заведении проекта**: fine-grained PAT
      выдаётся на конкретные репозитории, и прав ему нужно два - `Issues: write`
      и `Contents: read`. Без первого `/project` честно откажет, без второго
      заведётся проект без режима «Спросить»; старт называет это
      `github_read_denied`. planerka и qualifier покрыты обоими правами
      (владелец, 2026-08-17).
- [x] **Закрытые пачки задач**: очередь (0.1.7, срез queue-hardening), мелочи
      UX прогона сценариев (0.1.8), раунд без предположений (0.1.9). Состав - в
      [CHANGELOG](../CHANGELOG.md). Индексы под `payload->>'case_id'` и
      `cases(status)` сознательно не заводились: сканы росли из неубираемой
      таблицы, вернуться - если станут заметны.
- [ ] **Порог готовности зависит от формы обращения**: аккуратный текст
      проходит без вопросов, голосовое даёт раунд. Смотреть на обращениях
      заказчика; бедный тикет - поднимать планку промта.
- [ ] **Диалог перегружен сообщениями**: кандидаты на сжатие - сбор сразу после
      выбора проекта, протокол вместе с первым раундом. Решение владельца
      2026-08-08: смотреть на практике, пока не трогаем.
- [ ] **Golden-набор из реальных обращений**: подать боту сырьё, сравнить тикет
      с написанным руками. Единственная проверка качества интервью.
- [ ] **Отбор трёх файлов промахивается на размазанном ответе**: первый кандидат
      на правку режима «Спросить» после живого прогона. Смотреть на долю ответов
      «в документации этого нет» при том, что ответ в документации есть.
- [ ] **Один источник истины по формату ТЗ**: спека брифинга и шаблон PRD
      брифовщика опишут один артефакт; свести форматы до M6, спеки пока нет.
- [ ] **Удалить механику «вопрос проекта внутри сбора»**: `askProject` из
      `CollectItem` стал защитой от старых данных; убрать вместе с
      `ErrNoProject`, когда живые прогоны подтвердят новый поток. Там же
      ловушка пустого списка проектов при активном обращении.
