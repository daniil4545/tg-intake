## Milestones

- [ ] **M0** Каркас: Go, PostgreSQL, миграции, конфиг, белый список, JSON-логи,
      CI, private repo.
- [ ] **M1** Приём и нормализация: меню проекта и действий, сбор пачки до
      «Готово», транскрибация голосового, склейка протокола сырья, извлечение из
      скриншота с протоколом в контексте, удаление файлов.
- [ ] **M2** Интервью и публикация: контракт готовности, добивание раундами по
      2-3 вопроса, саммари с подтверждением, создание issue через outbox с
      авторством в шапке и метке, ответ автору. Замыкает Core.
- [ ] **M3** Dev-контур: Coolify, база, автодеплой из `dev`, живой прогон.
- [ ] **M4** Просмотр и жизненный цикл: список тикетов, карточка, статусы через
      метки, уведомления, комментарии, отмена, отклонение с причиной.
- [ ] **M5** Защита от мусора: дубли, лимиты. Нужен при открытии доступа шире
      белого списка.

M0-M3 составляют Core и дают работающий сервис. Версия к 2026-08-10 - это
M0-M3, только создание тикета. M4 делает из сервиса трекер и в срок не входит.

## Активные задачи

- [ ] **Блокеры до старта кода**: токен Telegram-бота, fine-grained PAT GitHub с
      правом Issues read/write на репозитории проектов, список Telegram ID для
      белого списка, решение владельца по порядку старта относительно открытых
      правок Саши по qualifier.
- [ ] **Проверить живьём приём ogg/opus** моделью Gemini через OpenRouter:
      модели с аудио на входе есть, поддержка контейнера ogg заявлена как
      зависящая от провайдера. Не принимает - ставим конвертацию ffmpeg в mp3
      безусловно.
- [ ] **Golden-набор из реальных обращений Саши**: подать боту исходные голосовые
      и скриншоты, сравнить полученный тикет с тем, что в итоге написано руками
      в спеках qualifier. Единственный способ проверить качество интервью.
