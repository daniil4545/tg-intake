- [x] **Живость поллера в healthcheck** - закрыто в 0.1.7 своим поллером:
      отказ опроса виден в логе, healthcheck смотрит на свежесть отметки.
- [x] **Уведомление, исчерпавшее повторы, молчит навсегда** - закрыто в 0.1.7:
      текст потери уходит алертом владельцу.
- [x] **Гонка двойной отмены тикета** - закрыто в 0.1.7 транзакцией и
      уникальным индексом. `replaceJob` семантику сохранил намеренно: фильтр
      статуса в DELETE оставил бы новую работу непоставленной, а снятие
      захваченной работы теперь видно в логе (`job_replaced_running`).
- [x] **Скриншоты одного обращения разбираются одним job** - закрыто в 0.1.7:
      работа на элемент плюс `finish_normalize`.
- [x] **Мелочи UX из прогона сценариев 2026-08-09** - закрыты в 0.1.8 все пять:
      окно меню гасит только пачку, кнопка «Продолжить» не меняет проект чужим
      slug, повторное «Всё так» отвечает про принятый ответ, отмена не
      предлагается по непрочитанному статусу, правка сообщения получает ответ.
- [x] **Раунд без предположений обещал кнопку «Всё так»** - закрыто правкой в
      `[Unreleased]` (переспрос модели, кнопка по факту догадок, правка промта),
      ждёт выката. Наблюдение контура 2026-08-14.
- [ ] **Порог готовности зависит от формы обращения**: аккуратный текст
