# Backlog

Границы и деление функций - [prd.md](prd.md). Здесь только порядок работ.
Runtime-снимок - [state.md](state.md).

## Milestones

- [ ] **M0** Каркас: Go, PostgreSQL, миграции, конфиг, JSON-логи, CI, private repo.
- [ ] **M1** Приём и нормализация: сбор пачки сообщений, извлечение из скриншота
      по схеме, транскрибация голосового, склейка протокола сырья, удаление файлов.
- [ ] **M2** Интервью и публикация: контракт готовности, добивание, саммари с
      подтверждением, создание issue через outbox, ответ автору. Замыкает Core.
- [ ] **M3** Dev-контур: Coolify, база, автодеплой из `dev`, живой прогон.
- [ ] **M4** Просмотр и жизненный цикл: список тикетов, карточка, статусы через
      метки, уведомления, комментарии, отмена, отклонение с причиной.
- [ ] **M5** Защита от мусора: триаж незнакомых авторов, дубли, лимиты.

M0-M3 составляют Core и дают работающий сервис. M4 делает из него трекер.
