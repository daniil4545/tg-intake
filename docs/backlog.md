## Активные задачи

      [acceptance/m4-lifecycle.md](acceptance/m4-lifecycle.md). Владелец, гейт B.
- [ ] **Расширять `GITHUB_TOKEN` при заведении проекта**: fine-grained PAT
      выдаётся на конкретные репозитории. Без права `/project` честно откажет.
      planerka и qualifier токеном уже покрыты (владелец, 2026-08-09).
- [ ] **Живость поллера в healthcheck**: telebot не отдаёт ни пустые циклы, ни
      ошибки опроса, healthcheck проверяет базу. Подорожало 2026-08-08:
      локальный `make run` с тем же токеном молча забрал апдейты у контура
      (`409 Conflict` второму поллеру), контур остался healthy. Ошибки поллера
      должны попадать в лог без `Verbose`: тот дампит тексты сообщений.
- [ ] **Один токен - один поллер**: локальный запуск обязан отличаться токеном
      от контура. Дешёвый вариант - отдельный тестовый бот в `.env.example`;
      решать вместе с живостью поллера.
- [ ] **Гонка на двойной отмене тикета**: `replaceJob` удаляет и вставляет
      работу без транзакции, два быстрых нажатия могут дать две параллельные
      работы. Итог для тикета одинаковый, страдает только аудит. Чинится
      уникальным индексом `case_events(case_id, kind)` либо транзакцией.
- [ ] **Порог готовности зависит от формы обращения**: аккуратный текст
      проходит без вопросов, голосовое даёт раунд (проверено 2026-08-08).
      Смотреть на обращениях заказчика; бедный тикет - поднимать планку промта.
- [ ] **Диалог перегружен сообщениями**: кандидаты на сжатие - сбор сразу после
      выбора проекта, протокол вместе с первым раундом. Решение владельца
      2026-08-08: смотреть на практике, пока не трогаем.
- [ ] **Golden-набор из реальных обращений**: подать боту исходное сырьё,
      сравнить тикет с написанным руками. Единственная проверка качества
      интервью и арбитр выбора моделей.
- [ ] **Один источник истины по формату ТЗ**: `plan-briefing.md` и шаблон PRD
      брифовщика описывают один артефакт по-разному. Свести до M6, вне этого
      репозитория.
- [ ] **Имя compose-проекта**: `name: intake` задано из-за совпадения каталога
      `src` у соседей. Локальная база на 5432 занята соседним сервисом -
      тестовый Postgres поднимать на своём порту.
- [ ] **Уборка очереди при следующей миграции `jobs`**: значение `remind` в
      CHECK не используется (напоминание идёт работой `notify`), таблица jobs
      не чистится, сканы по `payload->>'case_id'` без индекса. Заметно на
      порядки позже текущего масштаба.
- [ ] **Удалить механику «вопрос проекта внутри сбора»**: после закрытия входа
      обращение всегда начинается кнопкой с проектом, `askProject` из
      `CollectItem` стал защитой от старых данных. Убрать вместе с `ErrNoProject`
      отдельным заходом, когда живой прогон подтвердит новый поток.
