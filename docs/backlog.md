## Активные задачи

- [ ] **Выбрать модель диалога по живым прогонам**: текущая взята наугад.
      Сравнивать по времени шага и глубине размышлений в логе; кандидат
      переключается настройкой контура, без релиза.
- [ ] **Очередь не отличает невосстановимый отказ от временного**: отказ по
      правам проходит все шесть попыток, и честный ответ доходит до автора через
      минуту-две, хотя безнадёжность видна с первой. Каркасное - признак
      «повторять нет смысла» должна возвращать сама работа.
- [ ] **Расширять доступ к GitHub при заведении проекта**: токену нужны и запись
      тикетов, и чтение файлов. Без первого команда подключения честно откажет,
      без второго проект заведётся без режима «Спросить». Действующие проекты
      покрыты обоими правами (владелец, 2026-08-17).
- [x] **Закрытые пачки задач**: очередь (0.1.7, срез queue-hardening), мелочи
      UX прогона сценариев (0.1.8), раунд без предположений (0.1.9). Состав - в
      [CHANGELOG](../CHANGELOG.md). Индексы под `payload->>'case_id'` и
      `cases(status)` сознательно не заводились: сканы росли из неубираемой
      таблицы, вернуться - если станут заметны.

      проходит без вопросов, голосовое даёт раунд. Смотреть на обращениях
      заказчика; бедный тикет - поднимать планку промта.
