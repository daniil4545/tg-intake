# Срез 3: сценарии проверки eval-compare

Приложение к `plan-prompts-eval.md`, секция 3b. Issue: galera-tasks#32.

| # | Дано / когда / тогда | Что сломается | Факт | Ярус | Тест |
|---|---|---|---|---|---|
| 1 | средние на границах: M1 +0.10, M2 +0.10, M3 -0.05 ровно, M4 ниже на 0.001, доля `failed` +0.05 ровно | сравнение float без допуска режет границу | `pass`, допуск 1e-9 | быстрый | `TestEvalThreshold` |
| 2 | M4 равен базе; M1 +0.09; M2 +0.11; M3 -0.06; доля `failed` сверх базы+0.05 - по одному | не та метрика (или доля `failed`) в строке отказа | `fail`, в причине ровно эта строка | быстрый | `TestEvalThreshold` |
| 3 | замер из 1 прогона, пороги взяты | итерация сойдёт за приёмку | `fail`, причина `runs 1 of 3` | быстрый | `TestEvalThreshold` |
| 4 | база из 1 прогона; база с `failed` больше `evalFailLimit` (20%) в одном прогоне | сравнение с шумной или сломанной базой тратит ключ | `runsValid = false` - `t.Fatal` в `eval_test.go` до хода модели, `compareRuns` до неё не доходит | быстрый | `TestEvalThreshold` |
| 5 | `Bugs = 0` у замера или у базы | M3 = 0 по `share` даст ложный вердикт | `fail`, причина `M3: no bug cases` | быстрый | `TestEvalThreshold` |
| 6 | тип `mixed` только в замере | строка типа потеряна или паника на пустой базе | строка `mixed` с `-` в колонке базы | быстрый | `TestEvalThreshold` |
| 7 | ID: `bug` в базе и `mixed` в замере; `feature` в базе и `mixed` в замере | пересечение M3 берёт не те ID | в справке M3 пересечения только первый | быстрый | `TestEvalThreshold` |
| 8 | ID спрашивал в базе, молчит в замере; ID failed только в замере | справка без нужных ID | оба ID в своих строках таблицы | быстрый | `TestEvalThreshold` |
| 9 | база с другой моделью; набор без одного ID | дорогой прогон без сравнения | ошибка `sameSetup` | быстрый | `TestEvalThreshold` |
| 10 | `EVAL_OUT=base EVAL_BASE=base` | замер перезаписал базу | `t.Fatal` до прогона | ручной | журнал среза |
| 11 | `make eval-compare` без `base.json` | час прогона без сравнения | `t.Fatal` в первые секунды | ручной | журнал среза |
